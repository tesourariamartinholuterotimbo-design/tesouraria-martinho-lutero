💾 Backup e restauração

Os dados principais ficam na nuvem. O administrador pode baixar um backup a qualquer momento.

☁️ Google Drive
O backup é gerado pela tesouraria em arquivo JSON. Nesta versão, salve o arquivo baixado em uma pasta do seu Google Drive. A integração automática direta com o Drive será feita separadamente.

Use esta opção apenas uma vez, se você tiver dados da versão anterior neste mesmo endereço do aplicativo.

📱 Instalação no celular
Quando o sistema estiver aberto por um endereço HTTPS, use “Instalar app” ou “Adicionar à tela inicial”. A versão PWA já está preparada para isso.

⚙️ Configurações da tesouraria

Área administrativa. Somente o administrador pode alterar estes valores.

O percentual é aplicado aos valores de envelopes, mantendo a mesma regra de cálculo usada anteriormente.

👥 Usuários e acessos

As contas usam o Supabase Authentication. Para criar uma nova conta, o administrador deve abrir Authentication → Users → Add user. O primeiro usuário já foi reconhecido como administrador; novos usuários entram como colaboradores.

🔐 Regra de segurança
As senhas não ficam gravadas na aplicação. O Supabase faz o controle seguro do login.
