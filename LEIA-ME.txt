TESOURARIA MARTINHO LUTERO — V18.1 NUVEM
Atualização: 05/09/2026

MELHORIAS DESTA VERSÃO
1. BACKUP — Escolher onde salvar
- O botão “Escolher onde salvar” tenta abrir o seletor de arquivos do navegador.
- Se o navegador do celular não oferecer esse recurso, o arquivo é baixado normalmente em Downloads.
- O botão “Compartilhar / Salvar no celular” abre o compartilhamento do Android quando disponível, permitindo escolher Arquivos, Google Drive ou outro destino.

2. SAIR DO APP
- Corrigido o problema em que o botão Sair apenas recarregava a página e a sessão continuava ativa.
- Agora o aplicativo encerra a sessão do Supabase e volta para a tela de login.

3. COLABORADORES
- O aplicativo agora consulta a tabela profiles e mostra os usuários existentes ao administrador.
- O administrador pode ativar/desativar o acesso e alterar o perfil de outro usuário.
- Para CRIAR uma nova conta de login, por segurança, ainda deve ser usado Supabase → Authentication → Users → Add user.
- Depois da criação, o colaborador aparece automaticamente em Configurações → Usuários e acessos.
- Não são gravadas senhas dentro do aplicativo.

4. CULTOS ORGANIZADOS POR PASTAS
- Os cultos agora aparecem visualmente organizados por Ano e, dentro de cada ano, por Mês.
- O ano mais recente fica aberto.
- O mês mais recente fica aberto; os demais podem ser abertos tocando na pasta.
- Os registros continuam na nuvem exatamente como antes; isso é apenas uma organização visual, sem duplicar dados.

IMPORTANTE
- Esta versão não altera a estrutura principal do banco Supabase.
- Não é necessário executar uma nova migração SQL apenas para essas melhorias.
- Publique todos os arquivos desta pasta juntos no GitHub Pages.
- Depois de publicar, faça uma atualização forte/limpe o cache do PWA se o celular continuar mostrando a V17.0.

TESTE RECOMENDADO
1. Entrar como administrador.
2. Abrir Backup e testar “Escolher onde salvar”.
3. Testar “Compartilhar / Salvar no celular”.
4. Sair e confirmar que a tela de login aparece e NÃO entra sozinha.
5. Criar um novo usuário em Supabase Authentication → Users → Add user.
6. Entrar com esse usuário e confirmar que aparece como Colaborador.
7. Voltar ao administrador e testar ativar/desativar o colaborador.
8. Criar cultos em meses/anos diferentes e conferir as pastas.


V18.1 — Acesso de colaboradores:
- Cada colaborador usa seu próprio e-mail e senha do Supabase Authentication.
- O usuário pode alterar a própria senha em “Minha conta”.
- O administrador continua responsável por criar/desativar usuários e definir permissões.
- O botão “Compartilhar app” envia ou copia o link oficial do aplicativo.
- Após “Sair”, a sessão não é reaberta automaticamente até um novo login.
